# raitis.veinbahs.lv

Static site served from this repo at [raitis.veinbahs.lv](https://raitis.veinbahs.lv).

## Blog

The homepage, [`index.html`](index.html), has two stories:

- **New times, new trends!** (06.01.2026): staring at a wall is the hottest pastime of 2026.
- **Long time moka pot user sets record!** (01.09.2025): yet another moka pot burned in Jūrmala.

## Entrypoints

| Path | What it is |
|---|---|
| [`/`](https://raitis.veinbahs.lv/) | The blog. |
| [`/typeracer/`](https://raitis.veinbahs.lv/typeracer/) | Typing practice with a line that glides along at your typing speed. Built from [siers/TypeRacer](https://github.com/siers/TypeRacer) with `npm run package`. |
| [`/perflab/`](https://raitis.veinbahs.lv/perflab/?load=demo) | Prfl: a programmable music practice list with timers, a metronome and spaced repetition. |
| [`/drone-app/`](https://raitis.veinbahs.lv/drone-app/) | Plays a drone note to practise against; the notes to cycle through go in the URL hash. |
| [`/dual-dictionary/`](https://raitis.veinbahs.lv/dual-dictionary/) | Looks a word up in two Wiktionaries side by side (English and German or Russian). |
| [`/measure-intervals/`](https://raitis.veinbahs.lv/measure-intervals/) | Tap to measure the time between taps. |
| [`/gait/`](https://raitis.veinbahs.lv/gait/) | Tap out intervals and save them per person to compare. |
